# Reporting a vulnerability

If you find a security problem in Awaken Journal, please tell us first, privately:

**Email: support@everythingawaken.com** (English)

This matches our [security.txt](https://journal.everythingawaken.com/.well-known/security.txt).

Please include what you found, how to reproduce it, and what an attacker could do with it. Use test accounts only, and never access, change or delete another person's data. We'll reply, keep you updated while we fix it, and credit you if you'd like.

Please don't open a public issue for a vulnerability until we've had a chance to fix it.
